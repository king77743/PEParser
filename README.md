# Парсер файлов Portable Executable (PE) на чистом Си

Легковесная, сверхбыстрая консольная утилита на чистом C (без сторонних зависимостей) для анализа внутренней структуры исполняемых файлов Windows (`.exe`). Программа поддерживает как **32-битные (PE32)**, так и **64-битные (PE32+)** архитектуры, извлекает заголовки, таблицы секций и глубоко сканирует таблицу импорта функций (IAT).

Парсер считывает весь бинарный файл в память и работает через высокопроизводительную арифметику указателей. Это позволяет обрабатывать даже тяжелые и сложные исполняемые файлы (например, Wireshark) и генерировать огромные отчеты **меньше чем за одну секунду**.

## ✨ Возможности

- **Поддержка двух архитектур:** Автоматически распознает и парсит 32- и 64-битные PE-файлы.
- **Валидация сигнатур:** Проверяет DOS-заголовок (`MZ`) и PE-сигнатуру для подтверждения корректности файла.
- **Сбор метаданных:** Находит точку входа (Entry Point RVA), адрес таблицы импорта и смещение цифровой подписи (если она есть).
- **Карта секций:** Перебирает все секции (такие как `.text`, `.data`, `.rsrc`) с выводом их виртуальных адресов (RVA) и физических смещений на диске (RAW).
- **Глубокий парсинг импорта:** Находит все связанные DLL-библиотеки, подсчитывает их количество и обходит таблицу импорта, вытягивая имена функций и их порядковые номера (Ordinal numbers).

## 🛠️ Как это работает

Программа использует низкоуровневую навигацию по бинарным данным, включая:
1. **`RVAtoRAW`:** Ключевая функция, которая пересчитывает относительные виртуальные адреса (адреса в памяти при запуске) в физические RAW-смещения в файле на диске.
2. **Собственные форматировщики Hex/Dec:** Независимая логика перевода байт в текст для сохранения кастомной структуры логов.

## 📂 Структура проекта

- `PEParser_optimization.c` — Основная логика парсера, буферизация памяти и точка входа.
- `pe_structures.h` — Заголовочный файл с описанием структур PE-формата (`DOS_HEADER`, `FILE_HDR`, `SECTION_HEADER` и т.д.).

## 🚀 Инструкция по запуску

### Сборка
Для компиляции подойдет любой стандартный C-компилятор (GCC, Clang или MSVC).

Пример сборки через GCC:
```bash
gcc main.c -o pe_parser.exe
```

### Использование
Запустите скомпилированный файл. Программа попросит ввести путь к исследуемому `.exe` файлу и путь, куда сохранить текстовый отчет:
```text
Path: C:\Windows\System32\notepad.exe
Path to save result: C:\Users\User\Desktop\report.txt
```

```text
Section 3: .rsrc    | RVA: 0x22000    | RAW: 0x1F200
Section 4: .reloc   | RVA: 0x31000    | RAW: 0x2E400
Import Table RAW: 0002A000
DLL count: 4
DLL name: KERNEL32.dll
	GetLastError
	SetLastError
	FormatMessageA
DLL name: USER32.dll
	CreateWindowExA
	ShowWindow
	Ordinal number: 124
```
